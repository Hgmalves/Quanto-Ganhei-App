# Quanto Ganhei App

Aplicativo mobile em React Native/Expo para apoiar motoristas no controle da rotina financeira, com calendario de pagamentos e calculadora de combustivel.

![Expo](https://img.shields.io/badge/Expo-53-black)
![React Native](https://img.shields.io/badge/React%20Native-0.79-blue)
![JavaScript](https://img.shields.io/badge/JavaScript-ES6-yellow)

## Funcionalidades

- Tela inicial com navegacao simples.
- Calendario de pagamentos.
- Calculadora de combustivel.
- Interface mobile criada com React Native.
- Navegacao entre telas com React Navigation.

## Tecnologias

- Expo
- React Native
- React Navigation
- React Native Paper
- React Native Calendars

## Como executar

Instale as dependencias:

```powershell
npm install
```

Inicie o app:

```powershell
npm start
```

Depois, use o Expo Go no celular ou rode em um emulador:

```powershell
npm run android
npm run web
```
